# Story timelines

Pull the latest checkout and run the following with Docker Desktop running.

```sh
git pull --ff-only
sh bin/shared-content.sh timeline
```

On the default Mac installation, open **Timelines → MCU In-Universe Timeline** in the catalog navigation on [Site A](http://localhost:8080/site-a/timelines/mcu-in-universe/) or [Site B](http://localhost:8080/site-b/timelines/mcu-in-universe/). This also runs during a full setup. Running the command again preserves edits and existing publication states. You can change participation in **Network Admin → Shared Content → Sites and Content Types**.

To author a timeline, go to **Shared Content → Timelines → Create global record**. Add a title and an introduction. Optionally select a **Related franchise** so that its published page links to the chronology.

1. Add eras or phases and give each a color. Those labels appear in the public key and on each entry.
2. Add entries in story order and choose the movie or TV column. Enter an exact date, an approximate period, a relative label such as “Five years after the Snap,” or mark an entry undated. Move entries up or down, or enter a position to move directly there.
3. Enter the same section heading on consecutive entries to group them. Use a note to explain overlaps or links to another story.
4. Optionally find a shared movie or show by title. The published title supplies a link and poster where available. Choose artwork from the Media Library to override that poster. Entries can also stand on their own.
5. Save the global record, then publish it from the Timelines post list or use the existing publication controls in the ACF editor. Readers can filter the two columns by format and era.

The 56-entry MCU example follows selected main stories and separates branch timelines and the TVA. Phase color identifies when a production belongs in the MCU slate. The dates and placement describe when its story happens. The sample uses release-phase and chronological guidance from [Disney+](https://www.disneyplus.com/explore/articles/marvel-movies-in-order) and [Marvel](https://www.marvel.com/articles/movies/mcu-timeline-order-disney-plus).
